# Module Enclosure

## Status: NOT FINALIZED

## Main Module Contains
- ESP32-S3 + ESP32-C3
- USB-C port (accessible)
- Proximity sensor (externally facing)
- Buzzer (audible through enclosure)
- Medicine cylinder + dispenser + hatch + 2 servos
- Power distribution circuitry

## Expansion Module Contains
- Medicine cylinder + dispenser + hatch + 2 servos
- Connector interface (4 wires)

## Design Considerations
- Modules must physically lock together (slide rail / dovetail)
- Medication loading from top (cylinder access)
- Hatch at bottom or side for medicine retrieval
- Ventilation for electronics (if needed)
- Material: 3D printed (prototype), injection molded (production)
